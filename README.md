# WB-daily-checkin

让你的 WorkBuddy 每天自动帮你签到领积分。

一个开箱即用的「每日签到」技能：安装后，你的 WorkBuddy 可以直接运行它完成当日积分签到，并自动汇总本次获得、累计获得、当前余额、连续天数等信息；还能设置成每天定时自动签到，完全不用你操心。

## 它能做什么

- ✅ 自动完成当日签到，已签到则自动跳过（不重复）
- 📊 清晰汇总：本次获得 / 累计获得 / 当前余额 / 连续天数 / 当前活动
- 🤖 既能让 WorkBuddy 随时手动运行，也能设成每天自动执行
- 💻 跨平台：macOS / Windows / Linux

## 快速开始

把下面这段话复制后直接发给你的 WorkBuddy，它会自动从 GitHub 下载并安装这个 skill，并创建一个每天早上 9 点自动执行的签到任务：

```
请从GitHub下载安装这个skill：https://github.com/Keefe-Hu/WB-daily-checkin 安装完成后创建一个每天早上9点自动执行这个skill的定时任务
```

## 输出示例

WorkBuddy 运行后会给你一段清晰的结果：

```
✅ 签到成功
本次获得：5
累计获得：128
当前余额：342
连续天数：12
当前活动：每日签到领积分
```

## 关于登录

- 如果你本机已经登录了 WorkBuddy，安装后无需任何配置，WorkBuddy 直接就能签到。
- 如果换到没装 WorkBuddy 的机器，给 WorkBuddy 提供一次令牌即可运行，之后也能自动签到。
